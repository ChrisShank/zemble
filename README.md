# Zemble (Beta)

> A Zotero plugin for [Semble](https://semble.so), contextualize your Zotero references within the wider academic community and easily share your references with others.

## Docs

Check out the [docs](https://chrisshank.github.io/zemble/) to learn how to set up the plugin and how you can use it.

## Contributing

Bugs and feature requests can be filed [here](https://github.com/ChrisShank/zemble/issues). Checkout the [docs](/docs/README.md) for the structure of the repo and how to work with it locally. They are also translated to [chinese](/docs/README-zhCN.md) and [french](/docs/README-frFR.md).
